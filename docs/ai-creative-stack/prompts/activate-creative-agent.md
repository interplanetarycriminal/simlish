# Activate creative engineering

Follow the host project's instructions and the user's brief. Treat the creative stack as an optional catalogue of 44 tools, never a dependency list. Inspect the project and write measurable acceptance criteria. Record the creative direction in one `DESIGN.md`. Choose the minimum feasible tooling with [tool selection](../TOOL_SELECTION.md), and load only the guides for the capabilities the brief needs. Check [hardware](../HARDWARE.md), licenses and permissions, then verify the pinned upstream revisions, commands and installers. Define producer and consumer contracts, including versioned 3D stages and the [time contract](../docs/contracts/time-contract.md) where one scene plays live and renders. Implement, render the real outputs, critique them against the [quality gates](../QUALITY_GATES.md), refine and retest. Deliver the artifacts, commands, versions and evidence in an [execution report](../templates/execution-report.md), marking each integration as tested, documented or proposed. Record approved decisions in the project's decision log.
